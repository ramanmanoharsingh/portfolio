# Portfolio

Projects by **Raman Manohar Singh** across web development, machine learning, data analysis and embedded systems. Each project lives in its own folder with a README that explains what it does, how to run it and what it demonstrates.

**Live site:** [ramans.pages.dev](https://ramans.pages.dev)

## Projects

| Project | Area | Stack | What it shows |
|---|---|---|---|
| [PlayMatch Sports Network](projects/playmatch-sports-network) | Web app | HTML, CSS, JavaScript | Location-based matchmaking, fair ratings, match simulation, event logging |
| [Plant Disease Detector](projects/plant-disease-detector) | AI / ML | Python, TensorFlow, Streamlit, OpenCV | MobileNetV2 transfer learning, Grad-CAM explanations, confidence scores |
| [Titanic Kaggle ML](projects/titanic-kaggle-ml) | Data science | Python, Jupyter, pandas, scikit-learn | Preprocessing, modelling workflow, competition-style submission |
| [PlayMate Finder](projects/playmate-finder) | Web prototype | HTML, CSS, JavaScript | Player discovery interface, responsive layout |
| [Smart Street Lighting](projects/arduino-smart-streetlight) | Embedded | Arduino, C++ | LDR sensing with threshold hysteresis |
| [Soil Moisture Detector](projects/arduino-soil-moisture-detector) | Embedded | Arduino, C++ | Analog sensing, calibration, status indicator |
| [Python assignments](https://github.com/ramanmanoharsingh/python) | Fundamentals | Python | 19 scripts with recorded sample runs |

Two further projects are not hosted in this repository: a business sales management workflow, and a contribution to [oemlinker.com](https://oemlinker.com), a business website built with Emergent.
